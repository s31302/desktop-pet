# 🐾 Desktop Pet

## Jak pobrać?

1. Przejdź do zakładki **Releases** (po prawej stronie repozytorium).
2. Pobierz najnowszy plik `desktop-pet-v1.zip`.
3. Wypakuj zawartość w dowolnym miejscu na komputerze.
4. Uruchom plik `pet.exe`.
5. Ciesz się nowym zwierzakiem na pulpicie.

## Automatyczne włączanie z systemem
Jeśli chcesz, żeby zwierzak budził się razem z komputerem:
* Wypakuj pobrany plik.
* Kliknij dwukrotnie plik `dodaj-auto-start.ps1`.
* Skrypt doda skrót do folderu `Autostart`.
